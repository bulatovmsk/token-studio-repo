# Theme Switcher

Лёгкий Figma‑плагин: переключает тему (mode) одновременно во всех коллекциях Variables, которые используются в макете, либо сбрасывает все явно установленные modes.

## Как работает
1. Собирает все коллекции, реально используемые на выделенных узлах (или верхнеуровневых узлах страницы, если ничего не выделено) — через `boundVariables` узлов и paint'ов.
2. **Apply** — снимает явные режимы и назначает выбранную тему на каждом доступном узле, включая вложенные и скрытые слои инстансов. Обрабатывает все представления одной библиотечной коллекции.
3. **Полный сброс тем** — снимает явные режимы тематических коллекций на всех тех же узлах. Возвращает наследование, поэтому внутри инстансов может снова действовать тема из исходного компонента.
4. При выделении страница и соседние элементы не изменяются. Без выделения обрабатывается страница целиком. Ошибки назначения и сброса показываются в уведомлении, подробности — в консоли.
5. Сканирование учитывает привязки отдельных текстовых диапазонов. Коллекции без набора Main / Meta / Kids не затрагиваются.

Темы фиксированы: **Main**, **Meta**, **Kids**.

В списке, применении и сбросе участвуют только используемые коллекции, содержащие все три режима с этими точными именами. По текущему `themes/$themes.json` это **Color**, **Component W&M** и **Component TV**. Новые коллекции с теми же режимами подхватываются автоматически; Typography, Microcopy и технические коллекции не затрагиваются.

## Установка
1. Открыть Figma desktop.
2. Меню `Plugins → Development → Import plugin from manifest…`
3. Выбрать файл `plugin/manifest.json` из этого репозитория.
4. Запускать через `Plugins → Development → Theme Switcher`.

## Файлы
- `manifest.json` — манифест плагина.
- `code.js` — основная логика (Plugin API).
- `ui.html` — небольшой UI.
