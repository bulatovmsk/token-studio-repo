# KidsLight: прозрачные поверхности и цветные состояния

Основной фон — `cobalt200`, `#E6E5F5`, как в предоставленном
[концепте](https://www.figma.com/design/biiOtb8H1SxhfcTpD6PjxN?node-id=41920-9529).
Secondary-фон — белый `#FFFFFF`. Fill используется для айлендов, карточек и
контролов: primary — самая мягкая поверхность, secondary — заметнее,
third — плотнее. Glassy сохраняет альфу и адаптируется к подложке.

## Glassy: один цвет, разная альфа

Базовый цвет всех трёх уровней — `violet700`, `#7E3EFF`.

| Роль | Альфа | На основном фоне | На белом фоне |
|---|---:|---|---|
| `fill.glassy.primary` — крупные айленды | 6% | `#E0DBF6` | `#F7F3FF` |
| `fill.glassy.secondary` — карточки и плашки | 12% | `#DAD1F6` | `#F0E8FF` |
| `fill.glassy.third` — небольшие контролы | 18% | `#D3C7F7` | `#E8DCFF` |

Таблица показывает итог после смешивания с одним фоном, с округлением до
8 бит на канал. Вложенные поверхности смешиваются последовательно.

Hover/focus для secondary — градиент того же цвета от 12% до 18%, для third
— от 18% до 22%. Так состояние усиливает существующую заливку. Видимость
клавиатурного фокуса дополнительно обеспечивает отдельная рамка.

## Solid и контуры

Solid остаётся непрозрачным для случаев, где нужен фиксированный цвет:

| Роль | Заливка | Hover/focus |
|---|---|---|
| `primary` | `violet100`, `#F1EFFF` | `violet100 → violet300` |
| `secondary` | `violet300`, `#D6CFFF` | `violet300 → violet400` |
| `third` | `violet400`, `#C8BFFE` | `violet400 → cobalt500` |
| `fourth` | `cobalt500`, `#B4B2F9` | — |
| `selected` | `violet700`, `#7E3EFF` | — |
| Главная кнопка | `violet700 → cobalt1000` | — |

Primary подходит для крупных поверхностей. Third больше не белый и не
исчезает на secondary-фоне. Составные градиенты и их переменные
`gradient.fill.*.hover-focus.*.Step_1/Step_2` обновляются совместно.

Обычные контуры поверхностей мягкие: `border.solid` — `violet300`,
`border.glassy` — `violet700` 24%, `border.contour` — `violet700` 10%.
Им не назначается требование 3:1, если они выполняют декоративную функцию.

Для значимой границы контрола используется `border.active` — `cobalt1100`
80%; для focus — непрозрачный `cobalt1000`. Статусные контуры negative и
warning имеют непрозрачные варианты для значимых границ и glassy-варианты
с альфой 32% для декоративной подсветки вместе с читаемым текстом/иконкой.

## Контраст и проверка

```sh
python3 scripts/check_kidslight_contrast.py
```

Проверка разрешает реальные алиасы, выявляет циклы и битые ссылки, сверяет
градиенты и раздельные точки. Она также проверяет, что solid непрозрачен,
а glassy сохраняет альфу и последовательную градацию на обоих фонах.

Контраст рассчитывается после последовательного смешивания всех слоёв:
основной или белый фон → необязательный primary-айленд → необязательная
secondary-карточка → заливка/hover контрола → текст или контур. Проверяются
solid и glassy-варианты контейнеров, 1001 цвет на сегмент градиента и
прозрачность текста. Интерполяция градиента выполняется с учётом альфы.
Активный контур проверяется относительно обеих соседних поверхностей,
при расположении обводки внутри и снаружи. Порог оценивается без округления.

| Пара, минимум по проверенным контекстам | Контраст |
|---|---:|
| Основной / вторичный текст | 9,93:1 / 7,63:1 |
| Третичный текст | 5,57:1 |
| Акцентный текст | 4,65:1 |
| Положительный / отрицательный текст | 4,59:1 / 4,58:1 |
| Предупреждение и оффер | 4,63:1 |
| Активный контур / обе соседние поверхности | 3,32:1 |
| Белый текст / selected и градиент кнопки | 5,22:1 |
| Focus / светлые поверхности | 3,64:1 |
| Focus / белый промежуток | 7,38:1 |

Целевые требования: [контраст текста WCAG AA](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
— 4,5:1 для обычного текста; [нетекстовый контраст AA](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
— 3:1 для значимых графических элементов. Текстовые токены, selected,
градиент кнопки и ширина focus 3 px сохраняют значения предыдущей итерации.

## Применение

- Мягкая поверхность айленда или карточки не обязана иметь 3:1 относительно
  фона. Если граница необходима для распознавания контрола, использовать
  `border.active`; декоративная обводка её не заменяет.
- На selected/accent/главной кнопке использовать `text-icon.inverse.primary`
  без дополнительной прозрачности. Выбор дополнительно обозначать маркером.
- Focus отделять от акцентной заливки белым промежутком 2 px; проверить,
  что рамка не обрезается. Геометрия промежутка и маркер задаются компонентом,
  а не цветовыми токенами. Толщина 3 px — правило концепта, не требование AA.
- `text-icon.fourth` предназначен для неактивных элементов и декора.
  Читаемые подписи используют `text-icon.third`.
- В текущем контракте нет отдельных pressed-токенов и hover главной кнопки.
  Эта правка не добавляет новые пути, не меняет типы и Figma mappings.
- Альфа поверх произвольной фотографии, видео, более глубокие вложения и
  иные сочетания цветов требуют отдельной проверки. Результат проверки
  палитры не является подтверждением WCAG AA для всего приложения.
