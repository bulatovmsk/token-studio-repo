# KidsLight: цветные состояния и контраст

Изменение сохраняет сиреневый фон `#E6E5F5`, белые поверхности и текущий
градиент главной кнопки. Нейтральные интерактивные заливки и hover становятся
сиреневыми, активные контуры — фиолетовыми. Имена, типы и состав токенов,
Figma mappings и остальные темы не меняются.

## Заливки и состояния

| Роль | Обычная заливка | Hover/focus-заливка |
|---|---|---|
| `primary` | `violet400`, `#C8BFFE` | `cobalt600`, `#C3C1FA` |
| `secondary` | `violet200`, `#E3DFFE` | `violet300`, `#D6CFFF` |
| `third` | `white`, `#FFFFFF` | `violet200`, `#E3DFFE` |
| `fourth` | `cobalt500`, `#B4B2F9` | — |
| `selected` | `violet700`, `#7E3EFF` | — |
| Главная кнопка | `violet700 → cobalt1000`, `#7E3EFF → #5D0EF5` | — |

Для совместимости с экспортом hover/focus сохраняет тип градиента, но обе
точки имеют одинаковый цвет. Составные `color.fill.*.hover-focus.*` и
`gradient.fill.*.hover-focus.*.Step_1/Step_2` обновлены совместно.

В KidsLight базовые `fill.glassy.primary/secondary/third` и их hover-заливки
намеренно непрозрачны: читаемость контролов не должна зависеть от изображения
под ними. Это исключение для светлой темы, имена токенов сохранены.
Инверсные glassy-заливки, фоновые overlays и декоративные эффекты сохраняются;
их сочетания с изображениями требуют отдельной проверки.

## Текст и контуры

- `text-icon.primary/secondary`: прежние чёрный 96% / 80%.
- `text-icon.third`: непрозрачный `gray900`, `#3B3A3E`.
- `text-icon.accent`: `cobalt1100`, `#4F03CD`.
- `text-icon.positive`: `green1100`, `#005235`.
- `text-icon.negative`: `red1000`, `#94000A`.
- `text-icon.warning/offer`: `yellow1100`, `#5E410F`.
- `text-icon.inverse.primary`: непрозрачный белый для selected/accent/кнопки.
- Значимые `border.solid/glassy/active`: `violet900`, `#6C43BF`.
- Ошибки и предупреждения в обычных и glassy-контурах используют те же
  непрозрачные цвета, что и соответствующий текст.
- `border.focus`: прежний `cobalt1000`, `#5D0EF5`.
- `control.focus.width` в Component W&M KidsLight: 3 px вместо 1 px.
  В Component TV ширина уже 3 px.

Прежние цвета статусов также усилены: на насыщенной светлой заливке `fourth`
они не обеспечивали требуемые 4,5:1. `text-icon.fourth` остаётся только для
неактивных элементов и декора. Для читаемых подписей используется `third`.

## Проверка

```sh
python3 scripts/check_kidslight_contrast.py
```

Проверка читает реальные токены и Primitives/Brand, разрешает алиасы,
проверяет отсутствие циклов и битых ссылок, согласованность составных и
раздельных hover-градиентов. Прозрачность текста смешивается с фоном до
расчёта относительной яркости sRGB. Порог проверяется без округления.
Для градиентов проверяются точки и 1001 цвет на каждом сегменте.

Минимумы на основной и белой поверхности, всех базовых светлых заливках и
hover-состояниях, включая `fourth`:

| Пара | Минимальный контраст |
|---|---:|
| Основной / вторичный текст | 10,22:1 / 7,80:1 |
| Третичный текст | 5,74:1 |
| Акцентный текст | 4,79:1 |
| Положительный / отрицательный текст | 4,73:1 / 4,72:1 |
| Предупреждение и оффер | 4,77:1 |
| Значимый фиолетовый контур | 3,34:1 |
| Белый текст / selected и градиент кнопки | 5,22:1 |
| Focus / светлые заливки | 3,75:1 |
| Focus / белый промежуток | 7,38:1 |

Целевые требования: [WCAG 2.2, контраст текста AA](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
— 4,5:1 для обычного текста; [нетекстовый контраст AA](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
— 3:1 для значимых графических элементов. Толщина focus 3 px — правило
концепта, а не отдельное требование AA.

## Условия применения в компонентах

Эти условия требуют проверки в приложении/Figma после синхронизации; данный
репозиторий содержит только токены, поэтому правка JSON их не реализует:

- Когда граница нужна для распознавания контрола, использовать значимый
  контур, в том числе при сочетании белого с белым или близких сиреневых.
  Пастельные поверхности сами по себе не имеют контраста 3:1 между собой.
- Декоративные разделители могут использовать `border.contour`. Он и
  `border.decorative.*` не заменяют значимую границу и рамку фокуса.
- Вокруг focus предусмотреть белый промежуток 2 px, особенно на selected и
  accent. Проверить, что рамка не обрезается контейнером.
- На selected/accent/главной кнопке использовать `inverse.primary` без
  дополнительной прозрачности; выбор дополнительно обозначать галочкой
  или маркером. Hover не должен убирать этот индикатор.
- В текущем контракте нет отдельных токенов pressed и hover главной кнопки.
  Новые пути для них не добавлялись. Для нажатия нейтральных контролов
  концепт предусматривает: primary → `fill.solid.fourth`, secondary →
  `fill.solid.primary`, third → `fill.solid.hover-focus.secondary`.
- Произвольные изображения под прозрачными overlays, другие сочетания
  текста/градиентов, размеры текста, клавиатурное управление и видимость
  фокуса проверяются отдельно. Проверка палитры не подтверждает соответствие
  всего приложения WCAG AA.
