# KidsLight: контраст обычных семантических обводок

21 октября 2026 года. Снимок перед переработкой Solid/Active: белый
background.solid.secondary и смягчённый border.glassy на gray600 / 32%.
В этой проверке значения токенов не менялись.
Итоговая реализация после аудита описана в последнем разделе.

## Область

Только восемь обычных токенов: solid, glassy, active, contour, negative,
warning, negative-glassy, warning-glassy. Группа border.decorative и
border.focus исключены по запросу пользователя.

Проверены основной canvas, белый фон, gray200/300/400 и композиции
Solid/Glassy primary → secondary → third → Solid-fourth. Расширение:
10 именованных корневых контекстов, 230 именованных вариантов вложения,
70 уникальных Rest-поверхностей. Отдельно учтены 47 070 поверхностей
существующей проверки совместимости hover и 110 169 пар соседних цветов.

Для полупрозрачной линии сначала рассчитывается её итоговый цвет.
В таблице ниже контраст измерен к собственной заливке. Для границы двух
поверхностей дополнительно рассчитаны обе стороны линии и оба варианта
её наложения: поверх внутренней или внешней подложки.

Непрозрачные и активная значимые линии на проверенных светлых подложках
имеют запас к 3:1. Мягкие линии имеют другую роль: glassy/contour могут
почти совпасть с внешним фоном, хотя остаются заметны относительно
собственной заливки. Например, белый primary на background.glassy.fourth
поверх canvas даёт glassy лишь 1.054:1 с внешней стороны.
Их нельзя считать единственным средством определения границы или состояния.

Для статусных Glassy-заливок проверены canvas, white и gray200/300/400.
Negative на насыщенной красной заливке визуально отделяется существенно
слабее, чем на белом. Сам по себе результат 2.204:1 не доказывает нарушение
доступности: заливка, текст и иконка могут давать необходимую информацию.
Но рассчитывать только на различие красной линии с красной заливкой нельзя.

На selected / accent / inverse обводки для светлых подложек также теряют
разделение: solid даёт 1.624 / 1.275 / 1.275:1; active при наложении
поверх самой заливки — 1.767 / 1.455 / 1.455:1. При наружном наложении
active на светлый canvas и сравнении с accent/inverse минимум — 1.039:1.
Поэтому общий результат для светлых подложек не переносится на эти случаи.

## Вывод по иерархии

- Solid остаётся очень сильной фиолетовой линией. Для обычной рамки айленда
  он значительно тяжелее недавно смягчённого Glassy.
- Active на той же светлой поверхности слабее Solid: на белом 7.061 против
  10.029:1. Если активация должна усиливать именно рамку, иерархия спорная.
- Negative и Warning — сильные статусные линии. Их прозрачные варианты
  подходят для мягкого дополнительного статуса вместе с текстом или иконкой.
- Массовое смягчение всех восьми значений не требуется. Следующий кандидат
  на пересмотр — роль и цвет Solid; затем следует согласовать его с Active.
  Контекстные случаи на насыщенных заливках требуют отдельного решения.

Ориентир 3:1 относится к визуальной информации, необходимой для определения
компонента или состояния, а не ко всякой дополнительной линии:
[WCAG 1.4.11, Boundaries](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html#boundaries).
Эта проверка не подтверждает рендер приложения, произвольные изображения
или фактическое назначение токенов во внешних макетах.

## Реализация после аудита: Solid и Active

- `border.solid`: iris1000 → **gray500 / #BCBAC1**. Это непрозрачная
  нейтральная структурная рамка айлендов, а не единственная значимая граница
  контрола. По контрасту она располагается между мягким Glassy и Active.
- `border.active`: iris1100 / 80% → **iris800 / #5B40ED**, без прозрачности.
  Акцентная рамка активного светлого айленда теперь сильнее обычной.
- Остальные обычные значения, примитивы и mappings сохранены. Группы
  focus и decorative исключены из работы и не менялись.

| Подложка | Новый Solid | Новый Active |
| --- | ---: | ---: |
| Canvas | 1.545 | 4.966 |
| Белый | 1.921 | 6.175 |
| gray200 | 1.717 | 5.519 |
| gray300 | 1.513 | 4.863 |
| gray400 | 1.290 | 4.145 |

Расчёт по 110 169 парам соседних цветов с существующими hover сохраняет
минимум 1.289656:1 для Solid и 4.145273:1 для Active. На всём проверенном
светлом диапазоне Active сильнее Solid; это закреплено проверкой иерархии.

Порог 3:1 для Active и значимых статусных обводок не менялся. Solid исключён
из этой группы из-за нового назначения структурной рамки; его диапазон
выводится отдельно. Это изменение роли, а не успешная проверка Solid на 3:1.

Шкала относится к светлым айлендам. Новый Active совпадает с fill.selected
(1:1), на accent/inverse даёт около 1.275:1. Насыщенные контексты требуют
другой компонентной рамки; единого активного цвета для них эта пара не обещает.
Статусный случай negative на красной заливке из раздела выше не изменён.

## Последующее уточнение Contour и заливок

Contour переведён с iris1000 / 22% на **gray600 / 12%**: это слабый
нейтральный контур с контрастом 1.085–1.131:1 на поддержанных светлых
поверхностях. Он везде слабее Glassy на той же поверхности и не участвует
в проверке единственной значимой границы контрола. Focus и группа
decorative не менялись и не оценивались.

Одновременно gray200 / gray300 / gray400 затемнены до `#F0F0F2` / `#DDDDE1` /
`#CBCAD0` для разделения вложенных айлендов. На новом fourth Solid даёт
1.180:1, Glassy — 1.249:1; утверждение «Solid всегда сильнее Glassy»
больше не заявляется. Active остаётся сильнее обычных рамок и сохраняет
минимум 3.792:1 с обеих сторон проверенных смежных поверхностей.

Подробные значения и проверки зависимостей — в последнем разделе
[описания шкалы айлендов](kidslight-white-islands-2026-10-21.md#уточнение-контраст-между-заливками-и-слабый-contour).
